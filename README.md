# README-1

Uzdevums 1: Izveido Python programmu, kas pieprasa lietotājam ievadīt iegūto punktu skaitu (no 0 līdz 100) un, izmantojot if, elif un else, nosaka rezultātu.
90–100 punkti – «Izcili!»
75–89 punkti – «Labi!»
50–74 punkti – «Viduvēji!»
0–49 punkti – «Neieskaitīts!»
Ja ievadītais skaitlis ir mazāks par 0 vai lielāks par 100, izvada kļūdas paziņojumu.

Uzdevums 2:Izveido spēli, kurā dators nejauši izvēlas skaitli no 1 līdz 50, bet lietotājam tas ir jāuzmin.
Ja lietotājs ievada mazāku skaitli, programma paziņo, ka meklētais skaitlis ir lielāks.
Ja lietotājs ievada lielāku skaitli, programma paziņo, ka meklētais skaitlis ir mazāks.
Ja lietotājs uzmin skaitli, programma paziņo: «Apsveicu! Tu uzminēji!»
Programmai jāuzskaita mēģinājumu skaits.
Spēle turpinās, līdz lietotājs uzmin pareizo skaitli.

Uzdevums 3: Izveido Python programmu – kalkulatoru, kas spēj veikt četras matemātiskās darbības: saskaitīšanu, atņemšanu, reizināšanu un dalīšanu.
Lietotājam jāievada pirmais skaitlis.
Jāizvēlas matemātiskā darbība (+, -, *, /).
Jāievada otrais skaitlis.
Programmai jāaprēķina un jāizvada rezultāts.
Ja lietotājs mēģina dalīt ar nulli, jāizvada kļūdas paziņojums.
Ja ievadīta nepareiza darbība, jāizvada paziņojums: «Nezināma darbība!»
Pēc aprēķina programmai jāpiedāvā turpināt darbu vai beigt.
